# Grupo Êxito Imóveis — Quem Somos

Projeto acadêmico desenvolvido para a disciplina **Desenvolvimento Front-end para Web**.

## Sobre o projeto

Esta página apresenta a seção **Quem Somos** do Grupo Êxito Imóveis, com informações institucionais sobre a empresa, sua missão, visão, valores e diferenciais.

O objetivo foi desenvolver uma página organizada, de fácil leitura e adaptável a diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização, cores, layouts, efeitos de interação e responsividade.

## Recursos da página

- Apresentação institucional.
- Seções de missão, visão e valores.
- Cards com os diferenciais da empresa.
- Efeitos visuais ao passar o cursor sobre os cards.
- Layout responsivo para telas menores.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Contexto acadêmico

Projeto desenvolvido como parte das atividades da disciplina **Desenvolvimento Front-end para Web**.
